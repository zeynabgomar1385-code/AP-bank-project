 Development Notes (Important)

This project was developed collaboratively by Zeynab and Zahra as a university assignment.

During development, the project went through multiple feature branches.
At some stages, merge conflicts and structural bugs occurred, especially while merging UI-related branches into the main branch.

These issues were mainly caused by:

Parallel UI development on different branches

Folder structure changes during implementation

Missing files during initial merge operations

To resolve these problems:

The project structure was reviewed carefully

Missing core, widget, and UI files were manually restored

Conflicting or backup-related files were removed

The final main branch was stabilized after resolving all merge issues

All current features in the main branch are intentionally added, tested at UI level, and represent the final stable version of the project for academic evaluation.
